# JEPA-WorldEmergence
This research project investigates the emergence of structured world representations in large-scale Transformer-based models and Joint-Embedding Predictive Architectures (JEPA 2).

# Installation (on runpod.io)
```bash
cd workspace/
git clone https://github.com/quuixly/JEPA-WorldEmergence.git
cd JEPA-WorldEmergence
sudo apt update && sudo apt install tmux vim htop
pip install gdown
curl -LsSf https://astral.sh/uv/install.sh | sh
tmux new -s session
uv sync
```
